# BUG-2026-07-07T113000: Website docs build fails — missing React integration for TSX/JSX

## Problem

The Deploy Docs Site to GitHub Pages workflow fails with:

```
[PARSE_ERROR] Unexpected JSX expression in CockpitPage.tsx:9:9
Help: JSX syntax is disabled and should be enabled via the parser options
```

This has been failing silently (the workflow was never green) but was only caught now because the Codex template move triggered a fresh CI run.

## Root Cause

The website has 7 React TSX components under `src/components/cockpit/` but:
1. `@astrojs/react` was never installed — Astro requires this integration to parse `.tsx`/`.jsx` files
2. `astro.config.mjs` had no React integration configured
3. `tsconfig.json` lacked the `@/` path alias used by all cockpit components
4. Three npm packages (`yaml`, `clsx`, `tailwind-merge`) were missing dependencies used by the lib layer

The JSX parse error was the first build failure encountered; the missing packages and path alias were downstream errors that never surfaced because the build stopped at JSX.

Risk: Low (website build fix, no user-facing production code affected)

## Resolution

Fixed by:
- `@astrojs/react@6.0.1` + `react` + `react-dom` installed
- React integration added to `astro.config.mjs` integrations array
- `@/` path alias configured in `tsconfig.json`
- `yaml`, `clsx`, `tailwind-merge` installed as missing dependencies
